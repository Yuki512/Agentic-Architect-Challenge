# System Components
## Part 1: Support Email Agent

1. LangGraph - Connects the nodes, passes state and selects the next step.
2. Router Agent - Reads the email and selects its category.
3. BillingSubagent - Handles charges, payments, invoices and receipts.
4. RefundSubagent - Handles refunds, returns and cancellations.
5. TechnicalSubagent - Handles crashes, bugs and technical errors.
6. AccountSubagent - Handles login, password, profile and privacy questions.
7. ShippingSubagent - Handles delivery, tracking and package questions.
8. FeedbackSubagent - Handles suggestions, complaints and feedback.
